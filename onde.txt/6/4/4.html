🚀 SK Mini Editor

Gerador Interativo de Arquivos

ℹ️ Passo 1: Crie as pastas do projeto
1 Abra o Terminal/CMD

🪟 Windows: Pressione Windows + R, digite "cmd" e aperte Enter
🍎 Mac/Linux: Abra o Terminal

🪟 Windows - Cole isto:
Comando Windows
mkdir sk-mini-editor cd sk-mini-editor mkdir css mkdir js mkdir lib echo Estrutura criada!
🍎 Mac/Linux - Cole isto:
Comando Mac/Linux
mkdir -p sk-mini-editor/{css,js,lib} cd sk-mini-editor echo "Estrutura criada!"
✅ Após executar, você terá a pasta "sk-mini-editor" com as subpastas css, js e lib
ℹ️ Passo 2: Crie o arquivo HTML principal
📄 index.html
Caminho: sk-mini-editor/index.html
⚠️ Como fazer:
1. Abra um editor de texto (Notepad, VS Code, etc)
2. Cole o conteúdo acima
3. Salve como "index.html" na pasta sk-mini-editor
4. Certifique-se que é .html e não .txt
ℹ️ Passo 3: Crie os 9 arquivos CSS
⚠️ Como fazer:
1. Para cada arquivo CSS abaixo:
2. Copie o conteúdo
3. Cole em um editor de texto
4. Salve na pasta "css" com o nome exato
5. Exemplo: "style.css" na pasta "sk-mini-editor/css/"
ℹ️ Passo 4: Crie os 17 arquivos JavaScript
⚠️ Como fazer:
1. Para cada arquivo JS abaixo:
2. Copie o conteúdo
3. Cole em um editor de texto
4. Salve na pasta "js" com o nome exato
5. Exemplo: "mini-utils.js" na pasta "sk-mini-editor/js/"
✅ Parabéns! Você completou todos os passos!
